# 你知道“坐月子”的注意事项吗？

> 更新时间：2026-09-17 (UTC+8)

生完宝宝后 产妇 都要“坐月子”，那么这期间有什么注意事项呢？

一、 注意产妇的一般情况：于产后10日内应每天观察体湿、脉搏、呼吸和血压。产后最初24小时由于 分娩 体力消耗较大，体温会升高。但不应超过38度，产后10天内有反射 性 心率减慢至60-70次/分，产后腹压下降呼吸多深而慢约14-15次/分。

产后24小时内，应卧床休息，早期活动可促进子宫收缩使于恶露排出。应保证充分休息和睡眠，不能作重体力劳动以免发生子宫脱垂。

产后第一天可吃清淡易消化食物，以后饮食以富于营养、足够的热量为原则，多吃高蛋白和汤汁食物，适当补充 维生素 和铁剂。

产后尿量增多应尽量解小便。以免胀大膀胱妨碍子宫收缩。产后2日内应有大便。如有便秘，可用轻涂剂、开塞露、肥皂水灌肠等处理。

产后汗多要勤换内衣裤及床单，可用温水擦浴。保持室内空气流通、防止中暑、不宜用空调。

二、 会阴护理：每日可用温开水或消毒液冲洗阴部2-3次，保持会阴部清洁干燥。一般在产后4-5日拆除会阴缝线。

三、 注意观察子宫复原情况：摸测宫底高度逐日复原，产后10日后应在腹部摸不到，剖腹产产妇复原较慢应适当用宫缩剂，恶露有臭味应给抗炎治疗。

四、 注意乳房的护理：主张母乳喂养，产后可立即让婴儿皮肤接触。先用热肥皂水及清水将乳头乳晕洗净，以后每次哺乳前均用温毛巾擦洗乳头和乳房。母亲和婴儿均应取最舒服的位置，并用手托起乳房和挤压乳晕部位，乳房勿堵住婴儿鼻孔，哺乳时间次数可以不限定，吃饱为止，乳汁过多不能吸空，应将余乳挤去以促进乳房充分分泌乳汁。如果乳汁不足应补充牛奶。 哺乳期 限半年至1年为宜。

1、 如遇到乳房胀痛，产后尽早哺乳。哺乳前热敷乳房，可借助吸奶器，必要时用散结通乳药物。

2、 乳法不足，产妇精神愉快、睡眠充足、营养丰富、掌握正确授乳法，必要时可下奶药物。

3、 乳头皲裂，如有轻度皲裂可继续哺乳，要注意纠正婴儿是否仅吸住乳头用力过猛，应让婴儿张大嘴将乳晕部也吸住则不易引起香酊皲裂。哺乳后可用乳汁涂到皲裂部位。局部可用1%复方安息或10%鱼肝油剂，下次哺乳前要洗净，皲裂严重应用乳头罩间接哺乳。
